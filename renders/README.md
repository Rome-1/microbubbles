# Renders

Locally-rendered MIPs from the microbubbles ULM pipeline (epic mb-crr).
Generated by `scripts/local_view.py` from artifacts produced on Modal
(`scripts/modal/app.py::volume3d` / `baseline`). These are from the small
**6-acquisition validation** runs (not the full 223-acq baseline, which is the
canonical reference) — sparse on purpose.

| File | What it is |
| --- | --- |
| `01_baseline6_power_volume.png` | SVD power-volume MIPs (coronal/sagittal/axial). Coronal: point-like ULM signal. Sagittal/axial: horizontal **banding = residual clutter** to remove. |
| `02_baseline6_track_density.png` | ULM track-density MIPs — diffuse cloud + elevation-midplane pile-up, short fragmented tracks. |
| `03_insight_kalman_pred_tracks.png` | Same, with the predicted-state Kalman gate (mb-crr.10). Modest change (−4.7% tracks). |
| `04_diff_svd_aggressive_vs_baseline.png` | baseline vs aggressive SVD cutoff, signed coronal diff (red=more, blue=less). Modestly suppresses peripheral clutter. |

Full-baseline renders + the substantive clutter/detection-insight diffs land as those runs complete.
